# Dra. Stefani Melo

Site único em Next.js, personalizado a partir do template premium-vendas.

## Rodar localmente

Node.js 22 ou superior.

```sh
npm ci
npm run dev
```

## Vercel

Importe este repositório, escolha Next.js e mantenha a raiz do projeto. Build: `npm run build`. A Vercel detecta a saída automaticamente. Não requer banco de dados ou segredos.
